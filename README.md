### Как открыть работу

**Прочитать отчёт:** скачайте `QR_var5.html` и откройте его в браузере. GitHub показывает исходный HTML, а не интерактивный отчёт. Найденный готовый отчёт сохранён в HTML; отдельного PDF-отчёта в исходной папке не было.

**Открыть код:** используйте Pluto.jl или Advanced Pluto Notebook в VS Code. Рядом с `QR_var5.pluto.jl` должны находиться оба рабочих файла матриц; пути в ноутбуке вычисляются относительно его папки.

Ноутбук использует `LinearAlgebra`, `Random`, `Printf`, `Markdown`, `Test` и пакет `Plots`; сведения об окружении включены в файл. При сборке репозитория сохранённая работа перенесена без изменений и не пересчитывалась.

## Домашнее задание

### ДЗ №1 · Вариант 25

[Полное условие — PDF](homework/hw01/assignment.pdf)

| Функция | Отрезок |
| :--- | :--- |
| $f_1(x)=\cos x$ | $[0,2\pi]$ |
| $f_2(x)=\tanh x$ | $[-\pi,\pi]$ |

Для каждой функции необходимо:

1. Построить алгебраическую интерполяцию при числе узлов от **20 до 60** на равномерной сетке и сетке из нулей полиномов Чебышёва первого рода.
2. На тех же сетках построить **кубический сплайн Шёнберга**.
3. Получить априорные оценки погрешности и сравнить их с численными результатами.
4. Исследовать влияние чётности степени интерполяционного полинома на погрешность.

### Требования к сдаче

По сообщению преподавателя Анны Андреевой:

- Отчёт в **PDF**, фамилия студента — в названии файла.
- Код программы с подробными комментариями включается в отчёт и передаётся отдельно.
- Нужны теория, описание методов, формулы и оценки погрешности.
- Обязательны подписанные графики интерполяции и погрешностей, пояснения неочевидных действий и комментарии ко всем результатам.
- Источники кода, библиотеки и использование ИИ указываются явно. Отчёт, выводы и пояснения студент должен подготовить самостоятельно.
- После проверки проводится устная беседа: объяснение действий, теории и результатов. Оценки «хорошо» и «отлично» требуют защиты; без неё оценка снижается до «удовлетворительно (4)».
